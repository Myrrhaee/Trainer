# Achievement System v1

## Главная Идея

Achievement System в AI Strength Coach строится не как список случайных бейджей, а как **карта развития спортсмена**.

Система должна показывать путь клиента:

```text
Категория
↓
Коллекция
↓
Уровни наград
↓
Титул категории
↓
Абсолютный титул
```

Ключевая формула:

**Медали отражают путь. Кубки отражают уровень. Титулы отражают личность спортсмена.**

Достижения должны ощущаться как спортивная биография клиента, а не как декоративные иконки в профиле.

## Типы Наград

| Тип | Смысл | За что даётся |
| --- | --- | --- |
| Медали | Личный путь | Прогресс относительно себя: серии, регулярность, цель, замеры |
| Кубки | Абсолютный уровень | Объективные спортивные рубежи: жим 100 кг, 20 подтягиваний |
| Титулы | Мета-достижения | За закрытие крупных направлений развития |
| Секретные награды | Неожиданные события | Забавные, редкие или нестандартные сценарии |
| Почётные награды | История клуба | Бета-тестеры, основатели, сезонные события |

## Общая Логика

### Медали

Медали используются там, где критерий зависит от личного пути:

- процент достижения цели;
- количество выполненных действий;
- регулярность;
- чек-ины;
- замеры;
- фото прогресса;
- время с тренером.

Медаль говорит:

**“Я стал лучше относительно себя.”**

### Кубки

Кубки используются только для абсолютных спортивных рубежей, одинаковых для всех клиентов внутри сопоставимой группы.

Кубок говорит:

**“Я достиг объективного спортивного уровня.”**

Важно: силовые кубки в будущем должны учитывать пол, весовую категорию или другие параметры, чтобы сложность была сопоставимой.

### Титулы

Титул — это не просто награда за закрытие категории.

Титул — это новая идентичность спортсмена.

Не:

```text
Закрыл категорию → получил титул
```

А:

```text
Достижения категории + время + комплексный прогресс → стал человеком с этим титулом
```

Титул:

- не имеет уровней;
- открывается автоматически;
- отображается в hero-профиле;
- может отображаться рядом с именем;
- является предметом гордости;
- активным может быть только один титул.

### Секретные Награды

Секретные достижения не должны быть случайными.

Они должны быть:

- редкими;
- смешными;
- неожиданными;
- коллекционными;
- не влияющими на спортивный прогресс;
- вызывающими желание рассказать о них.

Секретные достижения:

- скрыты до момента получения;
- отсутствуют в общем списке;
- не влияют на титулы;
- не входят в общий процент прогресса;
- открываются красивой анимацией.

## Категории

| Категория | Смысл | Примеры коллекций |
| --- | --- | --- |
| Дисциплина | Регулярность и стабильность | Серии тренировок, чек-ины, активность, рекомендации |
| Сила | Абсолютные спортивные рубежи | Жим, присед, тяга, подтягивания, планка |
| Трансформация | Изменения тела и цели | Снижение веса, набор массы, фото, замеры |
| Форма | Качество тренировочного процесса | Кардио, мобильность, восстановление, гибкость |
| Клуб | Долгосрочная принадлежность | Стаж, сезонные события, секретные достижения |

Категории не должны быть одинаковыми по структуре. Каждая категория должна ощущаться как отдельный путь развития.

Например:

- **Дисциплина** — большая категория про привычки.
- **Сила** — меньше, но глубже, с кубками за конкретные рубежи.
- **Трансформация** — эмоциональная категория про личную цель.
- **Форма** — категория про здоровье, качество движения и устойчивость.
- **Клуб** — категория про принадлежность и историю.

## Категория: Дисциплина

### Смысл

Дисциплина отражает способность спортсмена регулярно выполнять тренировочный процесс и соблюдать договорённости с тренером.

Она не оценивает силу или результат.

Она оценивает постоянство.

### Коллекции

| Коллекция | Смысл |
| --- | --- |
| Серия тренировок | Выполнение тренировок подряд без пропусков |
| Выполненные тренировки | Общее количество завершённых тренировок |
| Время вместе | Сколько времени клиент занимается с тренером |
| Чек-ины | Регулярное заполнение чек-инов |
| Замеры | Регулярное обновление параметров тела |
| Фото прогресса | Загрузка фотоотчётов |
| Выполнение рекомендаций | Отметки тренера “рекомендация выполнена” |
| Возвращение | Возврат после длительных пауз |
| Без переносов | Тренировки без переносов |
| Онлайн-активность | Регулярное использование приложения |

## Категория: Сила

Сила не зависит от цели клиента. Если человек пожал 100 кг — это достижение независимо от того, худеет он или набирает массу.

## Категория: Трансформация

### Смысл

Трансформация отражает изменения тела спортсмена относительно его личной цели.

Здесь нет соревнования с другими людьми. Все достижения строятся вокруг собственного пути.

Это преимущественно медали, потому что человек побеждает себя, а не норматив.

### Коллекции

| Коллекция | Смысл |
| --- | --- |
| Путь к цели | Прогресс относительно главной цели клиента |
| Снижение веса | Используется, если цель клиента — похудение |
| Набор массы | Используется, если цель клиента — набор массы |
| Фото прогресса | Регулярные фотоотчёты |
| Замеры | Регулярные параметры тела |
| Композиция тела | Рекомпозиция: вес стоит, но форма улучшается |
| Стабильность веса | Удержание веса |
| Контроль веса | Движение без резких откатов |
| Новая цель | Продолжение пути после достижения цели |
| Фото “До и После” | Редкая эмоциональная коллекция |

### Примеры Медалей

#### Путь К Цели

| Медаль | Условие |
| --- | --- |
| Первый прогресс | Выполнено 25% цели |
| Уже близко | Выполнено 50% цели |
| Остался шаг | Выполнено 75% цели |
| Цель достигнута | Выполнено 100% цели |

Важно: достижения трансформации лучше считать не через фиксированные килограммы, а через процент выполнения цели.

Например:

- один клиент худеет с 140 до 90 кг;
- другой клиент худеет с 72 до 68 кг;
- третий набирает массу с 60 до 72 кг.

Абсолютные значения для них неравнозначны. Поэтому трансформация должна строиться вокруг личной цели.

**Архитектор тела**

Описание:

**“Ты не просто изменил цифры. Ты изменил себя.”**

## Категория: Форма

### Смысл

Форма отражает качество тренировочного процесса.

Она показывает, насколько спортсмен заботится о своём теле, а не только становится сильнее.

Если **Сила** отвечает на вопрос “насколько ты сильный?”, то **Форма** отвечает на вопрос:

**“Насколько качественно ты тренируешься?”**

### Коллекции

| Коллекция | Смысл | Статус |
| --- | --- | --- |
| Кардио | Кардиотренировки | MVP |
| Восстановление | Recovery workouts / восстановительные дни | MVP |
| Самочувствие | Чек-ины, усталость, боль | MVP, если данные есть |
| Без травм | Долгий период без жалоб | Осторожно |
| Баланс | Сочетание силовых, кардио, восстановления | MVP |
| Recovery Week | Выполненная восстановительная неделя | MVP |
| Сон | Сон и восстановление | V2 |
| HRV | Восстановление по биометрике | V2 |
| Гибкость | Тесты гибкости | V2 |
| Мобильность | Тесты мобильности | V2 |

Главное правило: достижения Формы должны быть честно измеримыми. Если продукт пока не собирает данные сна, HRV, гибкости или мобильности, такие достижения нельзя делать активными в MVP.

**“Ты научился не только прогрессировать, но и сохранять здоровье.”**

## Категория: Клуб

### Смысл

Клуб не должен быть свалкой всего остального.

Категория **Клуб** отвечает на один вопрос:

**“Насколько человек стал частью экосистемы AI Strength Coach?”**

Если дисциплина — это привычки, сила — спортивные достижения, трансформация — изменение тела, а форма — качество процесса, то клуб — это принадлежность и история.

### Коллекции

| Коллекция | Смысл |
| --- | --- |
| Верность клубу | Длительность отношений с тренером / платформой |
| Исследователь платформы | Изучение возможностей приложения |
| Постоянный участник | Регулярное использование платформы |
| Сезонные достижения | Сезонные челленджи |
| Особые даты | День рождения, Новый год, годовщина |
| Возвращение | Возврат после пауз |
| Пасхалки | Скрытые события |
| Наследие клуба | Неповторимые исторические трофеи |

- должны быть редкими;

## Редкость

### Смысл

Редкость нужна не для усложнения системы.

Она нужна, чтобы пользователь понимал ценность достижения.

Редкость должна вызывать эмоцию:

**“Вау, это получилось далеко не у всех.”**

Редкость не влияет на прогресс. Она влияет только на престиж и визуальное оформление.

### Уровни Редкости

| Редкость | Доля | Смысл |
| --- | --- | --- |
| Обычная | 40–45% / больше 60% на ранних достижениях | Большинство спортсменов получают её в процессе тренировок |
| Необычная | 20–60% | Требует регулярности и небольших усилий |
| Редкая | 5–20% | Получают мотивированные спортсмены |
| Эпическая | менее 5–10% | Требует месяцев или лет системной работы |
| Легендарная | менее 1–3% | Исключительно редкое достижение |

### Динамическая Редкость

В будущем редкость можно считать автоматически на основе реальной статистики:

```text
Получили 4,7% спортсменов
```

Так достижение может менять редкость со временем.

Например:

- в первый год жим 100 кг может быть эпическим;
- через три года он может стать редким, если таких спортсменов стало больше.

Для MVP можно заложить поле `rarity`, но не обязательно считать реальную статистику.

## Правила Выдачи

### Главный Принцип

Каждое достижение должно иметь:

- прозрачное условие;
- автоматическую проверку;
- однозначную выдачу.

Пользователь никогда не должен спрашивать:

- почему я получил достижение;
- почему я его не получил.

### Автоматическая Выдача

Все достижения выдаются автоматически.

Тренер не вручает достижения вручную.

Исключения:

- специальные административные достижения;
- сезонные награды;
- достижения бета-тестеров;
- почётные титулы.

### Проверка После Событий

После любого значимого действия система проверяет достижения.

| Событие | Что проверяется |
| --- | --- |
| Завершение тренировки | Серия, количество тренировок, PR, тоннаж, секретные достижения, титулы |
| Обновление веса | Прогресс цели, похудение, массонабор, трансформация |
| Загрузка фото | Фото прогресса, “До и После” |
| Чек-ин | Дисциплина, самочувствие, активность |
| Окончание дня | Серии, непрерывность, активность |
| Изменение цели | Пересчёт достижений относительно новой цели |

### Одно Достижение Выдаётся Один Раз

Любое достижение:

- открывается только один раз;
- не может быть потеряно;
- не может быть выдано повторно;
- сохраняет дату получения;
- остаётся в профиле навсегда.

### Медали

Медали имеют уровни:

```text
Бронза → Серебро → Золото → Мастер
```

Нельзя получить уровень выше, пропустив предыдущий.

### Кубки

Кубки независимы.

Если пользователь сразу достиг высокого рубежа, он получает все промежуточные кубки одновременно.

Пример:

```text
Жим 140 кг
↓
получает 100 кг, 120 кг и 140 кг
```

### Титулы

Титулы:

- выдаются автоматически;
- нельзя потерять;
- нельзя получить вручную;
- активным отображается один титул;
- пользователь может выбрать любой открытый титул.

### Секретные Награды

До получения:

- не отображаются в интерфейсе;
- не входят в общий прогресс;
- не учитываются в процентах выполнения.

После получения:

- становятся видимыми;
- получают описание;
- остаются в коллекции навсегда.

### Допустимые Критерии

Условия должны быть измеримыми.

Допустимые критерии:

- количество тренировок;
- количество дней;
- количество чек-инов;
- количество фотографий;
- количество замеров;
- рабочий вес;
- количество повторений;
- тоннаж;
- дата регистрации;
- серия тренировок;
- выполнение цели.

Запрещённые критерии:

- часто;
- всегда;
- хорошо;
- активно;
- регулярно.

Все условия должны содержать конкретное число или однозначное событие.

### Серии

Серия считается только при непрерывном выполнении условия.

Если серия нарушена, она начинается заново.

Пример:

```text
7 тренировок подряд
↓
одна тренировка пропущена
↓
серия сбрасывается
```

### Возврат После Паузы

Пауза считается только если клиент отсутствовал дольше установленного периода.

Базовый ориентир:

```text
30 дней
```

Возвращение после двух дней отдыха не считается достижением.

### Изменение Цели

Если клиент меняет цель:

- новые достижения рассчитываются относительно новой цели;
- полученные ранее достижения не удаляются;
- история сохраняется.

### Исправление Данных

Если тренер изменил тренировку задним числом или изменились исходные данные:

- система должна пересчитать достижения;
- некорректные достижения не должны оставаться в актуальном состоянии;
- при этом история получения должна быть обработана аккуратно.

## Защита От Злоупотреблений

Система не должна выдавать достижения за:

- дублирование тренировок;
- массовое редактирование данных;
- искусственное изменение веса;
- повторную загрузку одинаковых фотографий;
- отмену и повторное выполнение одного события;
- попытку накрутить серию через заднее число.

Все достижения должны рассчитываться только по валидным данным.

## Уведомления И Анимации

После получения достижения:

- появляется анимация;
- отображается описание;
- достижение сохраняется в профиле;
- событие появляется в “Жизни клуба”;
- тренер получает уведомление.

### Приоритет Выдачи

Если пользователь одновременно выполнил несколько достижений, они показываются по приоритету:

```text
Титул
↓
Кубок
↓
Медаль
↓
Секретная награда
```

Если достижений много, они объединяются в одну красивую последовательность.

### Интенсивность Анимации

| Редкость | Анимация |
| --- | --- |
| Обычная | Лёгкое уведомление, короткая анимация |
| Необычная | Более выразительная анимация |
| Редкая | Затемнение экрана, красивое появление |
| Эпическая | Отдельная полноэкранная сцена |
| Легендарная | Кинематографичная анимация, событие в “Жизни клуба”, уведомление тренеру |

## Визуальная Система

### Главный Принцип

Награды должны выглядеть как предметы, которые хочется собрать.

Пользователь не собирает иконки.

Он собирает историю своей спортивной карьеры.

### Медали

Медали:

- круглые;
- одинакового размера;
- отличаются материалом;
- имеют уникальную пиктограмму;
- показывают название, уровень и дату получения.

Материалы:

- бронза;
- серебро;
- золото;
- чёрный металл + золото / кристалл для мастер-уровня.

### Кубки

Кубки:

- крупнее медалей;
- выглядят престижнее;
- имеют форму, связанную с коллекцией.

Примеры:

- жим → кубок со штангой;
- подтягивания → кубок с турником;
- кардио → кубок с молнией.

### Титулы

Титул — это не предмет.

Он отображается как:

- герб;
- печать;
- эмблема;
- знамя;
- статус рядом с именем.

В профиле пользователя отображается только один активный титул.

### Секретные Награды

Секретные награды не используют общий шаблон.

Каждая выглядит как маленький коллекционный предмет.

Примеры:

- Полуночник → луна;
- Жаворонок → восход солнца;
- День рождения в зале → торт + гиря;
- Без выходных → праздничный объект со спортивным смыслом.

### Неоткрытые Достижения

Неоткрытые достижения не показываются полностью.

Используются:

- силуэты;
- тёмные предметы;
- скрытое название;
- скрытое описание.

После открытия происходит анимация раскрытия.

### Витрина Профиля

В hero / overview профиля отображаются только:

- активный титул;
- 3 любимые или последние значимые награды.

Остальные награды находятся в разделе:

**Коллекция.**

## Стартовые Достижения

Стартовых достижений должно быть мало.

Максимум:

```text
6 достижений
```

Цель стартовых достижений — научить пользователя системе, а не завалить наградами.

| Название | Тип | Условие |
| --- | --- | --- |
| Первый шаг | Медаль | Завершить первую тренировку |
| В ритме | Медаль | Выполнить 3 тренировки за первую неделю |
| Первая победа | Медаль | Поставить первый личный рекорд |
| На пути к цели | Медаль | Заполнить чек-ин и первые замеры |
| Часть команды | Медаль | Провести 30 дней с тренером |
| Первый рубеж | Медаль | Выполнить 10 тренировок |

## MVP-Версия

### Что Входит В MVP

В MVP достаточно реализовать:

- базовую модель достижений;
- витрину достижений в профиле клиента;
- горизонтальный скролл наград;
- 5 категорий;
- 20–30 системных достижений;
- статусы: открыто, в прогрессе, закрыто;
- прогресс до следующей награды;
- mock-данные;
- событие о достижении в “Жизни клуба”.

### Что Лучше Отложить

На потом:

- полноценный achievement engine;
- динамическая редкость по реальной статистике;
- сложная антиабуз-система;
- полноэкранные анимации для всех редкостей;
- сезонные челленджи;
- комьюнити-достижения;
- HRV, сон, мобильность, если этих данных ещё нет;
- ручная выдача специальных титулов админом.

## Главные Продуктовые Правила

1. Достижение должно ощущаться заслуженным.
2. Пользователь должен понимать, что именно он сделал.
3. Пользователь должен понимать, что нужно сделать дальше.
4. Нельзя выдавать награды за каждое простое действие.
5. Нельзя делать достижения, которые система не может честно измерить.
6. Медали — за личный путь.
7. Кубки — за объективные рубежи.
8. Титулы — за личность и долгий путь.
9. Секретные достижения — за эмоцию.
10. Визуально система должна ощущаться как комната трофеев, а не как список бейджей.

## Итоговая Формула

```text
Медали = я стал лучше относительно себя
Кубки = я достиг объективного спортивного уровня
Титулы = я стал человеком с новым статусом
Секретные = я сделал что-то редкое, смешное или неожиданное
Почётные = я стал частью истории клуба
```

После нескольких лет тренировок клиент должен открыть профиль и увидеть не набор иконок, а свою спортивную биографию:

- первые тренировки;
- первые рекорды;
- достигнутые цели;
- сложные возвращения;
- годы дисциплины;
- редкие победы;
- историю отношений с тренером;
- место внутри клуба.
